# Royal Feast Restaurant

A modern and responsive restaurant website built with HTML and CSS.

## Features

- Responsive design
- Premium restaurant UI
- Hero section with overlay
- About section
- Signature dishes
- Full menu
- Chef section
- Image gallery
- Table reservation form
- Customer testimonials
- Contact section with Google Maps
- Responsive layout for mobile devices

## Tech Stack

- HTML5
- CSS3
- Google Fonts
